# Changelog

All notable changes to AHI Module 2 will be documented in this file.

## [0.1.0] - 2024-01-01
### Added
- Initial implementation of Asset Health Index (AHI) methodology
- Environment factor, load factor, expected life, aging rate calculations
- Base health index, health modifiers, reliability modifiers
- AHI and Probability of Failure (PoF) calculation
- OpEx, CapEx, TotEx cost engines
- Future Health Index (FHI) projection
- Simulation runner for single assets and portfolios
- Calibration module using scipy.optimize
- Reporting modules (health, risk, maintenance, TotEx)
- Comprehensive test suite with ≥90% coverage
